1.Start the program.
2.Create a 5 × 8 array to store seat details.
3.Initialize all seats to 0 (Available).
4.Display the menu with six options.
5.Ask the user to enter their choice.
6.Perform the selected operation:- Display: Show all available and booked seats.
- Book: Check the row and seat number. If available, book the seat.
- Cancel: Check whether the seat is booked. If yes, cancel it.
- Group Reservation: Find the first row with enough consecutive available seats and book them.
- Occupancy Report: Display booked seats, available seats, occupancy percentage and busiest row.
- Exit: Display a closing message.

7.Display the updated seating arrangement after every successful booking or cancellation.
8.Repeat the menu until the user selects Exit.
9.Stop.
