1. Start the program.
2. Create a 5 × 8 array to store the seat details.
3. Initialize all seats to 0 (Available).
4. Display the menu with six options.
5. Ask the user to enter their choice.
6. Perform the selected operation:
   Display Seats: Show all 5 rows and 8 seats.
   Book Seat: Get row and seat numbers. If valid and available, book the seat by changing 0 to 1.
   Cancel Seat: Check whether the seat is booked. If yes, change 1 to 0.
   Group Reservation: Find the first row with enough consecutive available seats and book them.
   Occupancy Report: Display booked seats, available seats, occupancy percentage and busiest row(s).
   Exit: Display a thank-you message and stop the program.
7. Display the updated seating arrangement after every successful booking or cancellation.
8. Repeat the menu until the user selects option 6.
9. Stop the program.
